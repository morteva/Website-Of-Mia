# Fredoka — prepared, not activated

Downloaded from Google Fonts on October 3, 2026. No existing page, site stylesheet, or editor font selection loads or applies these files.

## Included files

- `Fredoka-Variable.ttf`: original full variable font from Google's fonts repository.
- `Fredoka-Latin.woff2`, `Fredoka-LatinExt.woff2`, `Fredoka-Hebrew.woff2`: Google Fonts' web-optimized variable subsets.
- `fredoka.css`: local `@font-face` declarations with the original Unicode ranges; no external font requests and no rules that change existing text.
- `OFL.txt`: required SIL Open Font License and copyright notice.

The font supports weights **300–700** and widths **75%–125%**, with normal width at 100%. This family contains the upright style.

## Future activation

Only when requested, load `/fonts/fredoka/fredoka.css` from the target page or shared site stylesheet. Then apply `font-family: "Fredoka", sans-serif` to the chosen element. Set `font-weight` and `font-stretch` as needed; for the specimen's standard width use `font-stretch: 100%`.

Keep the license with the font files. Do not change the site's current font tokens to activate Fredoka globally unless that is specifically requested.
